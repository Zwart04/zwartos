# ZWARTOS

Sumber daftar OS untuk **ZWARTOS** — netboot-style OS fetcher untuk flashdisk Ventoy.

Edit `zwartos-oslist.txt` untuk menambah OS baru atau memperbaiki link yang mati.
Semua flashdisk yang memakai ISO ZWARTOS otomatis menarik daftar terbaru dari sini saat online.

Format tiap baris:
- `Nama | https://folder/ | regex-nama-file`  (auto cari versi terbaru)
- `Nama | https://link-langsung.iso`           (link tetap)
